# Geometry Candidate Review Annotation UI Preview V1

## Scope

Geometry Candidate Review Annotation UI Preview V1 adds a read-only deterministic annotation preview to the existing Engineering Intelligence geometry candidate review workspace. The preview is limited to existing `possible_obstruction_candidate` candidates that remain in `review_required` state. It surfaces the DTO produced by `buildGeometryCandidateReviewAnnotation()` so reviewers can see the annotation schema, persistence mode, reviewer provenance, annotation note, reviewer confidence, tags, unchanged review state, projection-null behavior, and authority flags before any future persistence design is considered.

## UI Boundary

The workspace remains inspect-only. The annotation preview does not add form fields, editable inputs, submit handlers, live mutation handlers, API calls, database writes, projection creation, candidate approval, candidate rejection, canonical geometry mutation, CAD mutation, engineering influence, workflow influence, recommendation influence, roof-plane editing, setback creation, layout mutation, NEC authority, route authority, BOM authority, plan-set authority, or permit authority.

## DTO Contract Rendered

The preview renders the `geometry_candidate_review_annotation_v1` audit DTO generated by the assisted-evidence lifecycle boundary. The displayed metadata includes deterministic schema and persistence identifiers, reviewer display label, timestamp, reviewer confidence, note text, normalized tags, prior and resulting review state, `projectionCreated: false`, null reviewed projection references, candidate hash, annotation hash, runtime payload hash, source lineage, boundary policy, deterministic notes, and all-false authority flags.

## Safety Behavior

The annotation preview is intentionally separate from the existing disabled accept/reject action preview. It does not create a reviewed evidence projection and does not alter candidate status. `priorReviewState` and `resultingReviewState` remain identical for the previewed DTO. The preview uses deterministic sample annotation metadata only and remains unavailable for candidates that are not `review_required`.

## Validation Coverage

Targeted workspace coverage was updated to assert that the annotation preview appears with the annotation schema, deterministic DTO-only persistence, reviewer label, note, confidence, tags, no projection creation, null projection references, and no additional links or unsafe controls. Existing coverage continues to assert that only the disabled audited accept/reject buttons are present and that forbidden CAD, engineering, workflow, recommendation, and canonical mutation actions are absent.
