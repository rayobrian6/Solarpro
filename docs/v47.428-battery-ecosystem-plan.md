# v47.428 — Battery Ecosystem Smoke Suite + Battery SKUs

## Goal
Close the battery-ecosystem gap. Five hybrid brands (Solis, Tigo, Growatt, Sol-Ark, EcoFlow) declare `recommendedBatteryBrands` tokens like `byd`, `pylontech`, `tigo`, `eg4` — but NONE of those batteries exist in the equipment-db registry yet. This version:

1. Adds the missing battery SKUs (datasheet-verified)
2. Creates a Battery Ecosystem Smoke Suite that:
   - Asserts every `recommendedBatteryBrands` token resolves to ≥1 battery in the registry
   - Asserts every battery's ecosystemBrand is discoverable
   - Asserts datasheet-verified specs (capacity, power, voltage, chemistry, warranty)
   - Asserts battery schema integrity (required fields present, plausible ranges)

## Smoke Suite — stages

- **Stage 1 — Schema integrity**: every battery has id, manufacturer, model, usableCapacityKwh, chemistry, voltageNominalV, warrantyYears, ulListing, datasheetUrl
- **Stage 2 — Ecosystem resolution**: every `recommendedBatteryBrands` token in any BrandProfile resolves to ≥1 battery via `BATTERIES.filter(b => b.ecosystemBrand === token)`
- **Stage 3 — Capacity plausibility**: usableCapacityKwh in [1, 60], continuousPowerKw in [0.5, 30], voltageNominalV in [40, 500]
- **Stage 4 — Chemistry allowlist**: chemistry ∈ {LFP, NMC, Li-ion}
- **Stage 5 — Warranty coverage**: warrantyYears ≥ 5, capacityRetentionPct ≥ 50
- **Stage 6 — Brand-to-battery recommendation integrity**: for every hybrid BrandProfile with `battery.capable: true`, at least one recommended brand has a real battery SKU

Plus a Global invariant:
- **Global — No duplicate battery ids**
