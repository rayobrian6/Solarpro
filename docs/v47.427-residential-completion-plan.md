# v47.427 — Residential String Completion (Schneider + Victron + OutBack)

Goal: round out the residential off-grid / hybrid string-inverter ecosystem
using the v47.426 proven model. Three brands in one commit, datasheet-audited,
CI-gated via the v47.425 smoke suite.

## Target brands

### 1. Schneider — Conext XW Pro family
- Models: XW Pro 6848 NA (6.8 kW, 48V), XW Pro 5548 NA (5.5 kW, 48V)
- Topology: hybrid (inverter/charger, battery-based)
- 120/240V split-phase, grid-interactive, stackable up to 3 units
- Target audience: off-grid and whole-home backup

### 2. Victron — MultiPlus-II family
- Models: MultiPlus-II 48/3000, MultiPlus-II 48/5000
- Topology: hybrid (inverter/charger)
- Common in off-grid / marine / small-commercial
- Typically 120V single-phase (US)

### 3. OutBack — Radian GS Series
- Models: Radian GS8048A (8 kW), GS4048A (4 kW)
- Topology: hybrid (inverter/charger)
- 120/240V split-phase, stackable
- Legacy off-grid / backup focus

Note: these brands are fundamentally **inverter/chargers** (battery-first design).
The DC PV input side is often sized smaller than the AC output (unlike classic
grid-tie string inverters). Sizing tiers should reflect this — tiers map to
AC output kW, and the DC/AC ratio range tolerates down to ~0.6.
