DAY 2 — Webhook Verification
Verify Meta webhook handshake
In Meta Business Manager → Webhooks → Subscribe to leadgen field → Enter https://solarpro.app/api/intake/webhook/meta → Verify token matches META_WEBHOOK_VERIFY_TOKEN. Test with Meta's "Send Test" button. Should return 200 and create a test row in webhook_ingestion_log.
DAY 2–3 — Google Ads Setup
Create Google Ads campaign + lead form extension
Create campaign as "Search", enable Lead Form Extension, point webhook to /api/intake/webhook/google with X-Google-Key header = GOOGLE_WEBHOOK_KEY value. Use RSA with all headlines from this brief. Enable auto-tagging for gclid.
DAY 3–4 — Meta Ads Setup
Create Meta Lead Ad campaign
Build Lead Ad in Meta Ads Manager. Create Instant Form with the 3 custom questions. Upload customer list for Lookalike seed (min 100 emails, ideally 1,000+). Set budget to $30/day. Launch to all target states simultaneously.
WEEK 2 — First Optimization
Review Campaigns panel, optimize underperformers
Open admin Campaigns tab in SolarPro. Check leads_received vs target, actual CPL vs target. Pause keywords with CTR < 1%. A/B test ad headlines. Check enrichment_queue for failed enrichments.
WEEK 4 — Scale Decision
Double down on best-performing channel
Review 30-day data. Which channel has lowest CPL AND highest qualification rate? Shift 70% of Month 2 budget to that channel. Launch TikTok if Google and Meta are both performing above targets.
