## Datasheet-verification discipline (v47.418 rule)

Do not derive fake short-circuit values from 1.25 × operating. Use the
manufacturer-backed self-limited Isc value directly. For every SKU, the
datasheet test asserts the following fields against the literal datasheet values:

- acOutputKw, dcInputKwMax
- maxDcVoltage, mpptVoltageMin, mpptVoltageMax
- maxInputCurrentPerMppt, maxShortCircuitCurrent
- mpptChannels, maxParallelStringsPerMppt
- acOutputVoltage, acOutputCurrentMax
- efficiency, cec_efficiency
- ulListing, warranty
- rapidShutdownCompliant, arcFaultProtection
